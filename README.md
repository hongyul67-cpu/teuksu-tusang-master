# 🎭 특수 투상도 비교기 — 등각 · 사투상 · 투시

**기초제도 Ⅲ. 제도의 기본 도법 — 4. 특수 투상도 그리기** 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

투상법 이름은 외워도 "그래서 그림이 어떻게 달라지는데?"는 잘 와닿지 않습니다.
이 도구는 **똑같은 물체를 7가지 투상법으로 동시에 그려** 나란히 비교하고,
투시도에서는 **소실점(VP)이 실제로 어디 생기는지 빨간 점으로 표시**합니다.

소실점은 큰 수를 대입해 근사한 것이 아니라 **극한값을 해석적으로 계산**했고,
모든 물체·투상법 조합에서 소실점 개수가 정확한지 검증했습니다(정투상·등각·사투상 0개 / 1점 1개 / 2점 2개 / 3점 3개).

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **비교하기** | 물체 4종을 7가지 투상법으로 동시 표시. 소실점·수렴선 시각화, 시점 거리 슬라이더 |
| **도전 ①** 투상법 판별 | 그림을 보고 어떤 투상법인지 고르기 |
| **도전 ②** 소실점 개수 | 그림의 소실점이 몇 개인지 고르기 (평행투상 = 0개) |
| 🎯 **종합시험** | 두 유형을 섞어 10문항 출제 후 **결과 제출** |

## 수록 투상법

| 투상법 | 소실점 | 핵심 |
|--------|--------|------|
| 정투상도(정면도) | 0 | 실제 모양·치수 그대로, 입체감 없음 |
| **등각투상도** | 0 | 세 축이 120°, 세 방향 같은 비율 |
| **사투상도 — 카발리에** | 0 | 정면은 실제 모양, 깊이 **1배** |
| **사투상도 — 캐비닛** | 0 | 정면은 실제 모양, 깊이 **1/2배** |
| **1점 투시도** | 1 | 한 면이 화면과 평행 (실내·복도) |
| **2점 투시도** | 2 | 비스듬히 놓임, 수직선은 평행 (건물 외관) |
| **3점 투시도** | 3 | 올려보기·내려보기, 수직도 모임 (고층 건물) |

> **핵심 구분**: 평행투상(등각·사투상)은 소실점이 **없고**, 투시투상은 소실점이 **있습니다**.
> 학생이 그림만 보고 판단할 때 이 기준을 먼저 확인하도록 지도하면 좋습니다.

## 수업에서 쓰는 법

- **수업 자료**: `비교하기`에서 물체를 바꿔가며 7가지를 한 화면에 놓고 설명. 셀을 누르면 아래 큰 화면에 소실점까지 표시됩니다.
- **시점 거리 슬라이더**: 가까울수록 원근이 강해지는 것을 보여 주면 "왜 투시도가 사진처럼 보이는지" 설명이 쉬워집니다.
- **형성평가(제출)**: 주소 뒤에 `?rc=<Apps Script URL>` 을 붙여 배포하면, 종합시험 종료 시 학생이 **반·번호**를 넣어 제출하고 결과가 구글 시트에 모입니다.
